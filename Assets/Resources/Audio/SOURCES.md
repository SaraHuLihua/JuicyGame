# Sound effects: sources and licences

Every file in this folder was **generated by code** for Project Juice (Python + NumPy synthesis:
sine sweeps, filtered noise, a plucked-string model). No recording, sample or third-party sound was used,
so there is nothing to credit and no licence restriction: treat them as **CC0 / public domain**.

The generator script is not part of the game. Ask Claude to regenerate or change a sound.

Downloading free sounds (freesound.org, kenney.nl, opengameart.org, pixabay.com) was blocked by the network
policy of the environment that made this change. To use downloaded sounds instead, put a file with the
same name here (for example `launch.wav`), or add a GameAudio component to the scene and fill its Overrides.
For each downloaded file, add a line below with its source URL, author and licence.
